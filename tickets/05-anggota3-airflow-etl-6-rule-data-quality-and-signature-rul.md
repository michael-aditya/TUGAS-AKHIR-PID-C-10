# 05: [Anggota 3] Airflow Batch ETL DAG, 6-Rule Pandas Data Quality Engine & Signature Challenge (Health Index + 48h OLS RUL)

**What to build:** Deliver the batch ETL, 6-rule Pandas **Dirty Data** detection/imputation engine, and Signature Challenge predictive analytics module (Seam 2: `run_cnc_etl_pipeline`), orchestrated by an Apache Airflow DAG (`LocalExecutor`). The pipeline extracts raw **Telemetry Reading** documents and the out-of-band **Injection Audit Log** from MongoDB along with master reference data from MySQL, executes all 6 data quality rules (distinguishing real **Gradual Degradation** from non-physical **Out-of-Range Spike** and **Stuck Sensor** faults per ADR-0004), aggregates clean hourly metrics per **Machine**, computes the weighted **Health Index** (`0–100`) and 48-hour Ordinary Least Squares linear regression for **Remaining Useful Life (RUL)** toward the `7.1 mm/s` **Critical Vibration Threshold**, generates **Maintenance Due Alert** (`MAINTENANCE_DUE_RUL`) records whenever `RUL < 48 hours` as well as `fact_downtime_event` records for **Unplanned Downtime**, and loads the Star Schema and `dq_audit_summary` into PostgreSQL `cnc_dwh` using Anggota 2's warehouse loader.

**Blocked by:** 04: [Anggota 2] Star Schema Dimensional Warehouse Loader & Analytical BI Queries

**Status:** ready-for-agent

- [ ] Detects, logs, and repairs all 6 **Dirty Data** categories: (1) `missing_value` nulls imputed via per-device rolling median / forward-fill; (2) exact `(device_id, timestamp)` `duplicate` records deduplicated (`keep='first'`); (3) non-physical **Out-of-Range Spike** values (`< 0`, `vibration_rms_mms > 25.0 mm/s`, `spindle_temp_c > 150 °C`, `rpm > 20000`, `load_pct > 120%`) flagged and imputed via rolling median while preserving real **Gradual Degradation** (`4.5–15.0 mm/s`, `70–110 °C`); (4) **Stuck Sensor** runs (`>= 4` consecutive identical float values with `diff == 0.0000`) flagged and imputed; (5) `inconsistent_format` **Operational Status** strings (`"run"`, `"Running"`, `"idle "`, `"down_err"`) and non-ISO timestamps logged and normalized to `"RUN"`/`"IDLE"`/`"DOWN"` and ISO-8601 UTC; (6) `late_event` messages (`ingested_at - timestamp > 120s`) logged and assigned to their true event-time hour bucket.
- [ ] Reconciles detected **Dirty Data** counts per category against the simulator's out-of-band **Injection Audit Log** and persists the comparison to `dq_audit_summary`.
- [ ] Computes each **Machine**'s hourly **Health Index** (`0–100`) using normalized linear penalties weighted `50%` vibration (`0.5–7.1 mm/s`), `30%` spindle temperature (`30–85 °C`), and `20%` spindle load (`20–100%`).
- [ ] Fits an OLS linear regression (`y = a * t + b`) over the last 48 hours of clean hourly average vibration per **Machine** to estimate **Remaining Useful Life (RUL)** in hours until reaching `7.1 mm/s`, emitting a **Maintenance Due Alert** (`MAINTENANCE_DUE_RUL`) when `RUL < 48 hours` (confirming `CNC-07` triggers `MAINTENANCE_DUE_RUL` with `RUL ~ 28h` and `CNC-03` records `RUL = 0h` and **Unplanned Downtime**).
- [ ] Scheduled and triggerable Airflow DAG (`LocalExecutor`) runs the full extract-clean-analyze-load pipeline into PostgreSQL `cnc_dwh`, verified by automated tests across Seam 2.
