# 03: [Anggota 2] MySQL Master Data Reference & PostgreSQL Star Schema Data Warehouse Foundation

**What to build:** Deliver the relational OLTP master data source in MySQL and the OLAP Star Schema Data Warehouse plus real-time serving schema in PostgreSQL (per ADR-0003). MySQL (`cnc_master`) automatically initializes and seeds authoritative reference data for all 10 **Machine** assets (`CNC-01`..`CNC-10`: model, production line, installation date, service interval days, last service date, warning and critical thresholds for vibration and spindle temperature) and all 30 **Device** endpoints (`device_id`, `machine_id`, `device_type`, engineering unit, normal operating range, sampling rate). PostgreSQL (`cnc_dwh`) initializes the 4-dimension (`dim_machine`, `dim_sensor`, `dim_time` with **Production Shift**, `dim_failure_type`) and 3-fact (`fact_machine_hourly`, `fact_downtime_event`, `fact_alert`) Star Schema tables, the **Dirty Data** reconciliation summary table (`dq_audit_summary`), and the real-time serving tables (`rt_window_metrics`, `rt_active_alerts`) used as the sink for Anggota 1's Spark Structured Streaming job.

**Blocked by:** 02: [Anggota 1] MQTT-to-Kafka Ingestion Bridge, 7-Day Raw MongoDB Backfill & Spark Structured Streaming (1m/10m Windows & Real-Time Alerts)

**Status:** ready-for-agent

- [ ] MySQL (`cnc_master`) automatically initializes on container startup with populated master tables for 10 **Machine** assets (`CNC-01`..`CNC-10`) and 30 **Device** sensors (`CNC-XX-VIB`, `CNC-XX-SPD`, `CNC-XX-PRD`), including ISO 10816 vibration thresholds (`4.5` warning / `7.1 mm/s` **Critical Vibration Threshold**) and spindle thermal thresholds (`70.0` / `85.0 °C`).
- [ ] PostgreSQL (`cnc_dwh`) automatically initializes the 4 Star Schema dimension tables: `dim_machine`, `dim_sensor`, `dim_time` (with hour granularity, day attributes, and **Production Shift**: `Shift 1 Pagi`, `Shift 2 Sore`, `Shift 3 Malam`), and `dim_failure_type` (seeded with canonical **Failure Type** catalog: `VIB_WARNING`, `VIB_CRITICAL`, `TEMP_HIGH`, `OVERLOAD`, `MAINTENANCE_DUE_RUL`, `UNPLANNED_DOWNTIME`).
- [ ] PostgreSQL (`cnc_dwh`) initializes the 3 Star Schema fact tables (`fact_machine_hourly`, `fact_downtime_event`, `fact_alert`) with foreign-key constraints to the dimension tables, plus `dq_audit_summary` for injected-versus-caught **Dirty Data** reconciliation.
- [ ] PostgreSQL (`cnc_dwh`) initializes the real-time serving tables (`rt_window_metrics` and `rt_active_alerts`) and connects cleanly with the Spark Structured Streaming sink from Ticket 02.
