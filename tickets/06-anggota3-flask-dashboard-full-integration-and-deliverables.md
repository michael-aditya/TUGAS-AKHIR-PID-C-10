# 06: [Anggota 3] Interactive Flask Predictive Maintenance Dashboard, Full-Stack Integration & Deliverable Templates

**What to build:** Deliver the custom Flask web application (Seam 3: `create_app(repository)`), end-to-end Docker Compose integration, and complete course deliverable documentation and templates (fulfilling Milestone W5 / Checkpoint 2 and Milestone W6 / Final). The Flask dashboard provides an auto-refreshing industrial UI displaying real-time 1-minute and 10-minute windowed telemetry and **Machine** status cards (`RUN`/`IDLE`/`DOWN`), live **Health Index** gauges, **Remaining Useful Life (RUL)** badges, flashing **Maintenance Due Alert** banners (`RUL < 48h`), 7-day historical degradation time-series charts with linear regression projection lines toward the `7.1 mm/s` **Critical Vibration Threshold**, daily **Health Index** trends, rankings of **Machine** assets by **Unplanned Downtime** duration and alert count, hourly parts produced per **Machine** and **Production Shift**, an **Injection Audit Log** vs. ETL caught-count reconciliation table/chart, and a one-click "Trigger Manual ETL Refresh" button. Also provides automated HTTP tests at Seam 3, a zero-setup reproducibility guide (`README.md`), and structured templates for `laporan.md` and the 3 individual reflections (`refleksi/`).
